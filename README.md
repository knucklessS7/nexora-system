# Nexora System

## O que é o Nexora

O Nexora é uma personalização do Batocera 43 para computadores x86-64, com interface própria, Loja, navegador, atalhos de aplicativos e controle remoto pelo celular.

## Conteúdo do repositório

- Interface e tema do Nexora.
- Loja e atalhos de aplicativos.
- Smart Remote com pareamento por PIN e QR Code.
- Controle, mouse, teclado e gamepad virtual pelo celular.
- Arquivos de integração do sistema e do primeiro boot.
- Ferramentas para validar e preparar a imagem.

## Baixar a imagem

A imagem pronta para gravação está disponível no [site oficial do Nexora](https://nexora-download-oficial.marcianascimen658034.chatgpt.site/).

## Instalação básica

1. Baixe o arquivo `.img.gz` pelo site oficial.
2. Grave a imagem em uma unidade USB usando um programa compatível com imagens compactadas.
3. Reinicie o computador e selecione a unidade gravada no menu de boot.
